## 🌌 Filosofi Desain & Anti-AI-Slop Standard

Aplikasi ini dibangun dengan mematuhi prinsip estetika **Swiss Editorial Typography + Deep Cosmic Space**:
- **Zero Card Spam / Zero Bento Boxes**: Angka metrik utama (`2 days`, `12 hours`, `52`, `29%`) mengapung langsung di atas kanvas kosmik gelap gulita (`#03040B`) dengan memanfaatkan *pure negative space*.
- **Zero Emojis & Zero Generic Icons**: Tidak menggunakan emoji dekoratif atau ikon umum. Menggunakan tipografi tegas, tipis, presisi, dan garis pembatas mikron.
- **Micro-Starfield & Cinema Film Grain**: Latar belakang hidup dengan 60-80 partikel bintang berkelap-kelip lembut pada 60 FPS dan lapisan noise film analog tipis (`opacity: 0.03`).
- **Swiss Tabular Typography**: Menggunakan font `'Inter'` / `'Plus Jakarta Sans'` dengan `font-variant-numeric: tabular-nums`, tracking ultra-rapat (`tracking-[-0.04em]`), dan line-height super ketat agar sub-label biru elektrik (`#4D7CFE`) menempel pas di bawah angka raksasa putih.

## ✨ 5 Pilar Utama Aplikasi (5 Layar Interaktif)

### 1. The Live Streak Timer (`Tab 1`)
- **Left Stack**: Penataan asimetris angka raksasa 68px (`days`, `hours`, `minutes`, `seconds`).
- **Right Sculptural 3D Cosmic Orb**: Konstruksi konsentris 3 lapis (Atmospheric Corona, Glowing Rim Sphere, dan Abyssal Void Core) dengan efek bernapas 6 detik.
- **Hold 3s to Commit Today**: Tombol komitmen harian anti-batal dengan animasi pengisian 3 detik (+25 XP).
- **Emergency SOS Urge Shield**: Latihan pernapasan interaktif 4-7-8 (*Inhale 4s, Hold 7s, Exhale 8s*) untuk meredakan impuls godaan instan (+50 XP).

### 2. Origin Seed & Seed Vault (`Tab 2`)
- **Floating 3D Seed Artifact**: Visual patung 3D asteroid/benih organik yang berputar dinamis di ruang angkasa menggunakan kanvas shader procedural.
- **6 Tahap Evolusi Kosmik**: *Origin Seed (24h)*, *Sprout Core (3d)*, *Stellar Bloom (7d)*, *Nebula Root (14d)*, *Supernova Pod (30d)*, dan *Galactic Tree (90d)*.
- **Stasis Lock & Padlock Visuals**: Tahap yang belum tercapai terkunci dalam kristal stasis beku dengan penunjuk waktu yang dibutuhkan.
- **Epic Cosmic Unlock Celebration**: Animasi ledakan gelombang kejut kosmik (*shockwave*), letupan kembang api debu bintang, dan denting audio kemenangan saat artefak baru berhasil terbuka.

### 3. Rewire Your Brain (`Tab 3`)
- **Kartu Audio Tape Editorial**: Visual meditasi chiaroscuro dengan solar flare crimson/gold.
- **Synthesizer Gelombang Otak Web Audio API (100% Offline)**:
  - *Tape 1 (10 Hz Alpha Wave)*: Dopamine Reset — Menenangkan pikiran dan mengembalikan fokus.
  - *Tape 2 (6 Hz Theta Wave)*: Urge Dissolver — Melemahkan dorongan impulsif.
  - *Tape 3 (3 Hz Delta Wave)*: Deep Sleep Reboot — Relaksasi tidur dan regenerasi saraf.
- Dilengkapi visualizer audio real-time dan timer sesi (5m, 10m, 15m).

### 4. Mission Telemetry & Statistics (`Tab 4`)
- **Hero Metrics**: `52 potential time saved this week` dan `29% improvement vs last week` tanpa pembungkus kartu.
- **Last 7 Days at a Glance**: 7 lingkaran status harian dengan kode warna (*Neon Green* untuk bersih, *Dashed Border* untuk riwayat, *Electric Blue* untuk hari ini).
- **No Nut November Challenge**: Kartu tantangan komunitas dengan artwork 3D cosmic walnut dan tombol *Join the Challenge*.
- **Deep Analytics Drawer**: 30-Day Consistency Heatmap, grafik tren energi & fokus 7 hari, serta evaluasi jendela waktu rawan.

### 5. Shield & Privacy (`Tab 5`)
- **Pengingat Commit Harian (Daily Notification)**: Menjadwalkan pengingat di HP (default pukul 07:00 pagi) terintegrasi dengan Service Worker API dan tombol *Tes Notifikasi Sekarang*.
- **Pengatur Tanggal & Jam Mulai Streak**: Input `datetime-local` fleksibel untuk menyelaraskan timer dengan jam mulai nyata Master.
- **4-Digit PIN Lock**: Kunci keamanan 4 angka dengan papan keypad numerik kosmik.
- **Stealth / Discreet Mode**: Menyamarkan judul sensitif menjadi `Deep Focus` saat berada di tempat umum.

## 📱 Panduan Pemasangan ke HP (Android & iOS)

### Jalur A: Pasang Langsung via Browser (PWA)
1. Buka tautan [**evuaeru.github.io/seed-app/install.html**](https://evuaeru.github.io/seed-app/install.html) di browser ponsel (Chrome di Android atau Safari di iOS).
2. **Android**: Ketuk menu titik tiga (⋮) di Chrome > pilih **"Instal Aplikasi"** atau **"Tambahkan ke Layar Utama"**.
3. **iPhone / iOS**: Ketuk tombol **Share (Bagikan)** di Safari > pilih **"Add to Home Screen (Tambahkan ke Layar Utama)"**.
4. Aplikasi SEED akan langsung muncul di menu HP Master sebagai aplikasi mandiri berlayar penuh tanpa navigasi browser!

### Jalur B: Unduh File `.apk` Android
1. Masuk ke halaman [**GitHub Actions — Build Android APK**](https://github.com/evuaeru/seed-app/actions/workflows/build-apk.yml).
2. Pilih build terbaru dengan tanda centang hijau (✓).
3. Di bagian bawah (*Artifacts*), klik file **`SEED-Cosmic-Reboot-debug-apk`** untuk mengunduh arsip zip yang berisi file `.apk`.
4. Buka dan instal file `.apk` di perangkat Android Master.

## 🛠️ Pengembangan & Pengujian Lokal

```bash
# 1. Kloning repositori
git clone https://github.com/evuaeru/seed-app.git
cd seed-app

# 2. Instal dependensi
npm install

# 3. Sinkronisasi aset ke folder Android / www
node build.js

# 4. Jalankan 24 test suite otomatis
node --test tests/app.test.js

# 5. Jalankan server lokal
node server.js
# Buka http://localhost:4173 di browser
```
