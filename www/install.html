CROSS-PLATFORM INSTALLATION

Cara Pasang ke Layar Utama HP

SEED menggunakan teknologi Progressive Web App (PWA) & Offline Service Worker sehingga berjalan layar penuh seperti aplikasi native tanpa membebani memori HP.

01

Android (Chrome / Edge)

Ketuk tombol Instal Aplikasi Rilis atau Instal Aplikasi Demo di atas, lalu pilih "Install App" atau ketuk menu tiga titik di pojok kanan atas Chrome dan pilih "Tambahkan ke Layar Utama".

02

iPhone / iOS (Safari)

Buka versi aplikasi yang diinginkan (Rilis atau Demo), ketuk ikon Share (Bagikan) di bilah bawah Safari, lalu gulir dan pilih "Add to Home Screen" (Tambah ke Layar Utama).

03

File Installer Mandiri (.html)

Gunakan tombol Unduh Installer Rilis atau Unduh Installer Demo untuk menyimpan file peluncur aplikasi mandiri langsung ke penyimpanan perangkatmu.
